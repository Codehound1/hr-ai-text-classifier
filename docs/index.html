HR AI Text Classification Project

A Python, NLP, and Streamlit proof-of-concept for HR ticket routing and resume classification workflows.

Project Overview

This project demonstrates how unstructured HR text can be converted into structured categories that support routing, workflow automation, analytics, and human review.

Use Cases

Use Case 1: HR Ticket Routing

Classifies employee HR messages into categories such as Payroll, Benefits, Leave, IT Access, Recruiting, and Employee Relations.

I did not receive my direct deposit today.

Predicted Category: Payroll

Use Case 2: Resume Classification

Classifies resume-style text into broad job families such as Data Analyst / Data Engineer, Human Resources, Clinical / Healthcare, Software Engineering, and Finance / Accounting.

Epic Clarity analyst with SQL, Caboodle, Tableau, and healthcare compliance reporting experience.

Predicted Job Family: Data Analyst / Data Engineer

Technical Stack

Pythonpandasscikit-learn TF-IDFLogistic Regressionjoblib StreamlitNLP

How It Works

  1. Sample HR text and resume text are loaded from CSV files.
  2. Text is converted into numerical features using TF-IDF vectorization.
  3. A Logistic Regression model learns category patterns from labeled examples.
  4. The trained model predicts categories for new HR messages or resume text.
  5. A Streamlit app provides a simple web interface for demo purposes.

Business Value

  • Reduces manual triage for HR service teams.
  • Improves consistency in routing employee requests.
  • Supports candidate pipeline organization.
  • Creates structured categories from unstructured text.
  • Provides a foundation for HR analytics and workflow automation.

Responsible AI

This project is a proof of concept. In a real HR environment, AI predictions should support human review, not replace it. A production version should include bias testing, fairness checks, audit logging, privacy controls, security review, and compliance validation.
